Breakoutبرای تلویزیون سامسونگ

آجرشکن آرکیدی برای تلویزیون‌های سامسونگ ۲۰۲۱. کیبورد را به تلویزیون وصل کنید یا کنترل را بردارید، سوراخی در دیوار باز کنید و به بشقاب‌پرنده‌ای بزنید که پشتش پنهان شده.

دانلود برنامه کد در گیت‌هاب

رایگان و متن‌باز. آن را در حالت توسعه‌دهنده‌ی تلویزیون نصب می‌کنید و با گواهی تایزن خودتان امضا می‌کنید. نوشته‌های داخل بازی انگلیسی است.

روش بازی

هر مرحله دیواری از آجرهای باریک است و پشتش یک بشقاب‌پرنده به چپ و راست می‌رود. لازم نیست همه‌ی دیوار را خالی کنید. فقط باید توپ را به بشقاب‌پرنده برسانید.

  1. از دیوار رد شوید

    هر آجری که بشکنید امتیاز دارد، از ۱۰ برای آبی تا ۵۰ برای قرمز. شکافی باز کنید تا توپ به فضای پشت دیوار برسد.

  2. به بشقاب‌پرنده بزنید

    بشقاب‌پرنده به چپ و راست می‌لغزد و چراغ‌هایش رنگ‌های رنگین‌کمان را عوض می‌کنند. توپ که به آن بخورد ۵۰۰ امتیاز می‌گیرید، باقی دیوار محو می‌شود و مرحله‌ی بعد شروع می‌شود.

  3. جان‌هایتان را نگه دارید

    هر مرحله ۱۰ جان دارد. وقتی به بشقاب‌پرنده می‌زنید، کل امتیازتان در تعداد جان‌های باقی‌مانده ضرب می‌شود. پس مرحله‌ای که توپی در آن نیفتاده، همه‌ی امتیاز تا آن لحظه را ده برابر می‌کند.

  • سه دیوار. یک دیوار کامل، یک دیوار شطرنجی، و یک هرم زیر دو ردیف آجر نقره‌ای که هر کدام دو ضربه می‌خواهند.
  • بعد تندتر. بعد از مرحله‌ی ۳ دیوارها دوباره می‌آیند و هر دور توپ ۱۰ درصد تندتر شروع می‌کند. با شکستن آجرها هم کم‌کم سرعت می‌گیرد.
  • همه‌ی جان‌ها رفت؟ همان مرحله را با امتیازی که با آن شروع کرده بودید دوباره بازی کنید، از مرحله‌ی ۱ از نو شروع کنید، یا به صفحه‌ی اول برگردید.
  • رکوردتان می‌ماند. بهترین امتیاز روی همان تلویزیون ذخیره می‌شود. برای هر برخورد یک بوق کوتاه آرکیدی پخش می‌شود و با M بی‌صدا می‌شود.

کنترل‌ها

هر کیبورد USB یا بی‌سیمی را به تلویزیون وصل کنید، یا فقط از کنترل استفاده کنید. کلید را نگه دارید تا راکت بلغزد، رها کنید تا بایستد.

نصب روی تلویزیون

Breakout در فروشگاه برنامه‌ی سامسونگ نیست. آن را از کامپیوتری که با تلویزیون در یک شبکه است نصب می‌کنید، با ابزارهای خط فرمان tizen و sdb از Tizen Studio.

  1. ۱

    حالت توسعه‌دهنده را روشن کنید

    روی تلویزیون Apps را باز کنید (در بعضی مدل‌ها App Settings)، روی کنترل ۱ ۲ ۳ ۴ ۵ را بزنید و Developer mode را روشن کنید. آی‌پی کامپیوترتان را وارد کنید و تلویزیون را دوباره راه بیندازید. بعضی مدل‌ها پیش از اولین نصب، Permit to install applications را هم از Device Manager در Tizen Studio می‌خواهند.

  2. ۲

    پروفایل امضا بسازید

    تلویزیون سامسونگ فقط برنامه‌ی امضاشده نصب می‌کند و کلید امضا باید پیش صاحبش بماند، پس Breakout را خودتان امضا می‌کنید. در Certificate Manager از Tizen Studio یک پروفایل گواهی بسازید. اگر تلویزیون آن را نپذیرفت، از گواهی سامسونگی استفاده کنید که DUID تلویزیونتان در آن ثبت شده باشد.

  3. ۳

    پوشه‌ی برنامه را بگیرید

    فایل breakout-tv-app.zip را از صفحه‌ی انتشارها دانلود کنید و از حالت فشرده دربیاورید تا پوشه‌ی app را داشته باشید. یا آن را از کد بسازید که در dist/app قرار می‌گیرد:

    git clone https://github.com/cocodedk/breakout-tv.git
cd breakout-tv
npm ci
npm run stage
  4. ۴

    بسته‌بندی، نصب، بازی

    اگر فایل دانلودی را باز کرده‌اید، به‌جای dist/app بنویسید app. دستور tizen package فایل را Breakout.wgt می‌نامد؛ پیش از نصب نامش را به app.wgt تغییر دهید. گزینه‌ی -t نام دستگاهی را می‌گیرد که sdb devices نشان می‌دهد.

    tizen package -t wgt -s MyProfile -- dist/app
sdb connect 192.168.1.50:26101
tizen install -n app.wgt -t MyTV -- dist/app
tizen run -p BreakoutTV.Breakout -t MyTV

زیر کاپوت

برنامه‌ی تلویزیون تایزن در اصل یک وب‌سایت است در یک فایل زیپ، همراه با config.xml. Breakout فقط HTML و CSS و جاوااسکریپت ساده است که در مرورگر خود تلویزیون اجرا می‌شود و هیچ دسترسی‌ای به اینترنت ندارد.

مرورگری که هیچ‌وقت به‌روز نمی‌شود
تلویزیون ۲۰۲۱ روی Chromium 76 می‌ماند. کد از هر چیز جدیدتر مثل ?. و ?? دوری می‌کند و یک مرحله‌ی lint آن را رد می‌کند.
بدون مرحله‌ی build
تگ‌های script ساده یک فضای نام window.BO را با هم شریک‌اند. نه ماژول، نه bundler، نه فریم‌ورک، نه پکیج در زمان اجرا.
یک کنترل‌کننده، دو ورودی
کیبورد و کنترل هر دو رویداد کلید می‌فرستند و بازی keyCode را می‌خواند که تلویزیون برای هر دو درست پر می‌کند.
تست بدون تلویزیون
دستور npm run check این‌ها را اجرا می‌کند: lint سازگاری، تست‌های واحد فیزیک و امتیاز، و درایوهای Playwright که بازی را با کلیدهای ساختگی در ۱۹۲۰×۱۰۸۰ بازی می‌کنند.
