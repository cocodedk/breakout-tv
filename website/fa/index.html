Breakoutبرای تلویزیون سامسونگ

آجرشکن کلاسیک، ساخته‌شده به‌شکل یک برنامه‌ی وب تایزن برای تلویزیون‌های سامسونگ ۲۰۲۱. کیبورد را به تلویزیون وصل کنید یا کنترل را بردارید، توپ را رها کنید و دیوار آجرها را خالی کنید.

دانلود برنامه کد در گیت‌هاب

رایگان و متن‌باز. برای تلویزیون‌های سامسونگ ۲۰۲۱ (تایزن ۶٫۰) با حالت توسعه‌دهنده‌ی روشن.

داخل بازی چه خبر است

سه مرحله، سه جان و یک رکورد برای شکستن. مثل آرکید اصلی است، فقط برای نشستن روی مبل.

  • راکت و توپ

    کلید را نگه دارید تا راکت بلغزد، رها کنید تا بایستد. توپ بسته به جای برخوردش با راکت به سمت دیگری می‌رود.

  • آجرهای رنگی

    ردیف‌های قرمز، نارنجی، زرد، سبز و آبی، و آجرهای نقره‌ای که دو ضربه می‌خواهند. هر چه ردیف بالاتر باشد، امتیازش بیشتر است.

  • سه مرحله

    یک دیوار پر، یک شطرنجی و یک قیف نقره‌ای. هر سه که تمام شد، دوباره از اول شروع می‌شود، این بار تندتر.

  • جان و امتیاز

    سه جان دارید. توپ را از دست بدهید، یکی کم می‌شود. بهترین امتیازتان روی همان تلویزیون ذخیره می‌شود.

  • صدای آرکید

    برای هر برخورد، هر آجر شکسته و هر توپ از دست‌رفته یک بوق کوتاه پخش می‌شود. با کلید M ساکتش کنید.

  • کیبورد یا کنترل

    هر دو با هم کار می‌کنند. چیزی برای جفت‌کردن نیست و برنامه‌ی گوشی هم لازم ندارید.

  • مناسب مبل

    صفحه ثابت و ۱۹۲۰×۱۰۸۰ است و هیچ نوشته‌ای کوچک‌تر از ۲۸ پیکسل نیست.

  • کاملاً آفلاین

    بدون حساب کاربری، بدون تبلیغ، بدون دسترسی به اینترنت. برنامه فقط فایل‌های خودش را دارد.

نصب روی تلویزیون

Breakout در فروشگاه سامسونگ نیست. باید آن را از یک کامپیوتر هم‌شبکه با تلویزیون نصب کنید.

  1. ۱

    حالت توسعه‌دهنده را روشن کنید

    روی تلویزیون به Apps بروید، روی کنترل ۱ ۲ ۳ ۴ ۵ را بزنید و Developer mode را روشن کنید. آی‌پی کامپیوترتان را وارد کنید و تلویزیون را ریستارت کنید.

  2. ۲

    گواهی امضا بسازید

    تلویزیون سامسونگ فقط برنامه‌ی امضاشده نصب می‌کند. با ابزارهای خط فرمان تایزن یک پروفایل گواهی بسازید. اگر تلویزیون بعداً ردش کرد، یک گواهی سامسونگ بسازید که DUID تلویزیونتان در آن ثبت شده باشد.

  3. ۳

    برنامه را بسته‌بندی کنید

    مخزن را کلون کنید، برنامه را آماده کنید و با پروفایلتان بسته‌بندی کنید.

    git clone https://github.com/cocodedk/breakout-tv.git
cd breakout-tv
npm run stage
tizen package -t wgt -s MyProfile -- dist/app
  4. ۴

    نصب و اجرا

    آدرس تلویزیونتان و نام دستگاهی را بگذارید که sdb devices نشان می‌دهد. بعضی تلویزیون‌ها پیش از اولین نصب، Permit to install applications را هم از Device Manager در Tizen Studio می‌خواهند.

    sdb connect 192.168.1.50:26101
tizen install -n Breakout.wgt -t MyTV -- dist/app
tizen run -p BreakoutTV.Breakout -t MyTV

در صفحه‌ی انتشارها برنامه به‌صورت یک فایل zip بدون امضا هست: breakout-tv-app.zip. آن را از حالت فشرده دربیاورید و پوشه‌ی app را مثل مرحله‌ی ۳ با پروفایل خودتان بسته‌بندی کنید.

زیر کاپوت

برنامه‌ی تلویزیون تایزن در اصل یک وب‌سایت است در یک فایل زیپ، به‌همراه config.xml. Breakout فقط HTML و CSS و جاوااسکریپت ساده است و در مرورگر داخلی تلویزیون اجرا می‌شود.

مرورگری که هیچ‌وقت آپدیت نمی‌شود
تلویزیون ۲۰۲۱ روی Chromium 76 می‌ماند. کد از سینتکس جدیدتر مثل ?. و ?? دوری می‌کند و یک مرحله‌ی lint چنین چیزی را رد می‌کند.
بدون مرحله‌ی build
تگ‌های script ساده یک فضای نام window.BO را به اشتراک می‌گذارند. نه ماژول، نه bundler، نه فریم‌ورک، نه پکیج در زمان اجرا.
یک کنترل‌کننده برای هر دو ورودی
کیبورد USB و کنترل هر دو رویداد کلید می‌فرستند. بازی keyCode را می‌خواند، چون مرورگر تلویزیون آن را درست پر می‌کند. Back روی کنترل ۱۰۰۰۹ است و روی کیبورد Esc.
گام ثابت فیزیک
توپ با گام‌های ۱/۲۴۰ ثانیه حرکت می‌کند، پس توپ تند هم از وسط آجر رد نمی‌شود.
تست بدون تلویزیون
دستور npm run check این‌ها را اجرا می‌کند: lint سازگاری، تست‌های واحد فیزیک و امتیاز، و درایوهای Playwright که بازی را با کلیدهای ساختگی در ۱۹۲۰×۱۰۸۰ می‌زنند.
