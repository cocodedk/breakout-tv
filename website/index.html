Breakoutfor Samsung TV

The arcade brick breaker for 2021 Samsung TVs, played out on a deep-space sky. Pick up the remote or plug in a keyboard, break through three walls to the UFO behind each, then take on the battle station that shoots back.

Download the app Source on GitHub

Free and open source. You install it in the TV's developer mode and sign it with your own Tizen certificate.

Four walls, one boss

Every wall hides a target. Behind the first three, a UFO slides back and forth with its lights cycling through the rainbow. Get the ball to it and the rest of the wall dissolves. You never have to clear every brick.

Then round again, faster. After level 4 the walls come back from level 1 and the ball starts 10% faster each time. It also picks up speed as a wall wears down. Every level is open from the start: pick where to begin on the title screen.

    Hit the UFO or the station

    The ball touching the UFO on levels 1 to 3, or the station on level 4, ends the level: the rest of the wall dissolves and the next one begins.

  • +1,000

    Bat a bolt back

    On level 4, catch a green bolt on the paddle. It flies back gold and destroys every brick it touches, silver ones too, scoring each as if the ball had broken it. If it reaches the station it's worth 1,000 more.

  • × lives

    Keep your lives

    You get 10 lives on every level. When a level ends, your whole score is multiplied by the lives you have left.

Hold to speed up

The paddle starts off gently and gets faster the longer you hold the key, so a tap nudges it and a long press sends it across the screen. Let go and it stops.

Back always does something: in play it pauses, in a menu it closes it, and on the title it asks before leaving. Every bounce beeps, and hitting the UFO sets off a layered crash; M turns the sound off.

Install it on your TV

Breakout isn't in Samsung's app store. You install it from a computer on the same network as the TV, with the tizen and sdb command line tools from Tizen Studio.

  1. 1

    Turn on developer mode

    On the TV, open Apps (App Settings on some sets), press 1 2 3 4 5 on the remote and switch Developer mode on. Enter your computer's IP address, then restart the TV. Some sets also want "Permit to install applications" from Tizen Studio's Device Manager before the first install.

  2. 2

    Make a signing profile

    A Samsung TV installs only signed apps, and a signing key should stay with its owner, so you sign Breakout yourself. Create a certificate profile in Tizen Studio's Certificate Manager; tizen security-profiles list shows it. If a retail set turns it down, use a Samsung certificate with your TV's DUID registered.

  3. 3

    Get the app folder

    Download breakout-tv-app.zip from the latest release and unzip it to get an app folder. Or build it from the source, which puts it in dist/app:

    git clone https://github.com/cocodedk/breakout-tv.git
cd breakout-tv
npm ci
npm run stage
  4. 4

    Package, install, play

    Use app instead of dist/app if you unzipped the download. tizen package names the file Breakout.wgt: rename it to app.wgt before you install. -t takes the device name sdb devices prints, not the IP address.

    tizen package -t wgt -s MyProfile -- dist/app
sdb connect 192.168.1.50:26101
tizen install -n app.wgt -t MyTV -- dist/app
tizen run -p BreakoutTV.Breakout -t MyTV

Under the hood

A Tizen TV app is a website in a zip file with a config.xml. Breakout is plain HTML, CSS and JavaScript running in the TV's own browser, with no network access at all.

A browser that never updates
A 2021 TV runs Chromium 76 and stays there. The code avoids anything newer, such as ?. and ??, and a lint step rejects it.
No build step
Classic script tags share one window.BO namespace: no modules, bundler or framework. The sky, the UFO and the station are drawn by the game itself, not loaded as pictures.
One handler, two inputs
A keyboard and the remote both send key events, and the game reads keyCode, which the TV fills in reliably for both.
Tested without a TV
npm run check runs the compatibility lint, unit tests for the physics, the station and the scoring, and Playwright drives that play all four levels at 1920×1080 with synthetic keys.
